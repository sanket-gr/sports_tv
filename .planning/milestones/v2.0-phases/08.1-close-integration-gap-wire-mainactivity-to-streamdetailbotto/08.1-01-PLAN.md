# Plan 08.1-01: Close Integration Gap — Wire MainActivity to StreamDetailBottomSheet

Resolve the cross-phase integration gap where `MainActivity` directly launches `PlaybackActivity` upon card selection instead of opening the `StreamDetailBottomSheet` detailed channel info dialog.

## Proposed Changes

### Mobile App Module

#### [MODIFY] [MainActivity.kt](file:///d:/projects/sports_tv/android_tv_app/mobile/src/main/java/com/sportstv/mobile/MainActivity.kt)
- Modify the `streamAdapter` initialization in `onCreate` (lines 57-59):
  - Instead of invoking `PlaybackActivity.start(this, stream)` directly, instantiate the `StreamDetailBottomSheet` using `StreamDetailBottomSheet.newInstance(stream)`.
  - Set `onFavoritesChangedListener` on the bottom sheet to call `refreshCurrentView()` (or `updateViewForTab(currentTabId)`) so the favorites tab list updates instantly when toggled.
  - Show the bottom sheet: `bottomSheet.show(supportFragmentManager, "StreamDetailBottomSheet")`.
